Módulos del sistema

Todo lo que necesitás, en un solo lugar

Cada módulo fue diseñado para simplificar las tareas administrativas diarias del cementerio, reduciendo el margen de error y mejorando el tiempo de respuesta.

Gestión de Parcelas

Control visual e interactivo del estado de cada parcela en tiempo real. Zonas A, B, C y D con disponibilidad actualizada al instante.

Registro de Difuntos

Alta, consulta y baja de registros con datos completos del fallecido: nombre, CI, fechas, parcela asignada y responsable vinculado.

Administración de Responsables

Vinculación directa entre cada difunto y su responsable: datos de contacto, parentesco y seguimiento centralizado en un solo registro.

Historial de Movimientos

Trazabilidad completa de todos los ingresos, bajas y cambios del sistema. Cada acción queda registrada con fecha, tipo y parcela involucrada.

Búsqueda Rápida

Localizá difuntos y responsables en segundos por nombre, CI o número de parcela. Resultados instantáneos con búsqueda inteligente.

Mapa Interactivo

Visualización gráfica del cementerio con parcelas coloreadas por estado. Al hacer clic, accedés a la información completa de cada espacio.

Protección de datos

Su información, segura y protegida

Cada registro está respaldado por infraestructura en la nube con autenticación de acceso, cifrado y control de permisos administrativos.

Autenticación segura

Solo el personal autorizado puede acceder al sistema mediante credenciales verificadas. La sesión se cierra automáticamente por inactividad.

Almacenamiento en la nube

Los datos se almacenan en Supabase, una plataforma de base de datos PostgreSQL con respaldo automático y alta disponibilidad.

Control de acceso (RLS)

Las políticas de seguridad a nivel de fila (Row Level Security) garantizan que cada usuario solo vea los datos que le corresponden.

Información confidencial bajo resguardo permanente

El sistema fue diseñado respetando las buenas prácticas de seguridad informática, garantizando que los datos de los difuntos, responsables y parcelas estén disponibles únicamente para el administrador autorizado.
